개인정보처리방침

시행일: 2026-09-23

1. 접근하는 정보

이 도구는 Google OAuth로 운영자 본인의 YouTube 채널에 대해 다음 권한만 요청합니다: 동영상 업로드, 운영자가 올린 동영상의 공개 상태·예약 시각·메타데이터(제목, 설명, 태그) 수정, 채널 식별 정보 확인.

2. 이용 목적

운영자가 직접 제작한 영상을 운영자 소유 채널에 업로드하고 예약 공개를 설정하는 데에만 사용합니다. 광고, 분석, 프로파일링, 판매에 사용하지 않습니다.

3. 저장과 보관

OAuth 토큰은 운영자의 컴퓨터 안(macOS 키체인)에만 저장되며 외부 서버로 전송되지 않습니다. 운영자는 언제든 Google 계정의 서드파티 액세스에서 권한을 철회할 수 있고, 철회 시 저장된 토큰은 더 이상 쓸 수 없습니다.

4. 제3자 제공

수집한 정보를 제3자에게 제공하거나 공유하지 않습니다.

5. Google API 서비스 사용자 데이터 정책

이 도구가 Google API로 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 문의

문의는 Google 동의 화면에 표시된 지원 이메일로 해 주십시오.
